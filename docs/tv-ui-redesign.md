# OneFilm TV 端 UI 重构方案

> **文档状态（2026-10-21）**：历史设计/交接/回归记录，部分内容已被后续实现覆盖。最新项目进度以 [`2026-10-21-project-status.md`](2026-10-21-project-status.md) 和 [`compose-ui-roadmap.md`](compose-ui-roadmap.md) 为准。


- 日期：2026-10-20
- 范围：仅 `leanback` TV 端；手机端现有白灰 iOS 设计保持不变
- 目标：建立独立于手机端的 Apple TV 式大屏布局与遥控器焦点体系
- 依据：`docs/superpowers/specs/2026-10-19-compose-ui-design.md` + 本轮确认项

## 1. 已确认的视觉方向

| 项目 | 结论 |
|---|---|
| 主题 | 保留当前白灰浅色，不切深色影院 |
| 顶部 | 三行结构：品牌/接口名/时间 → 主导航 → 接口分类 |
| 品牌 | 左侧 `ONEFILM` 大字品牌 |
| 时间 | 右侧日期 + 时间，等宽数字 |
| 接口名 | 中间显示当前接口名称（如 `ONETV影视`），有公告时优先显示公告 |
| HERO | TV 端取消 Hero |
| 内容 | 5 列铺满屏宽，2 行；空间不足时纵向滚动，横向按页切换 |
| 分类页 | 与首页一致：5 列海报 + 横向分页 |
| 焦点 | 导航/分类聚焦深色胶囊；海报 1.05 缩放 + 白色细环 |
| 手机端 | 完全不动，继续使用当前底部 Tab 与现有首页 |

参考布局：欧歌影视 TV 首页（2400×1080），原结构为品牌/接口名/时间 → 分类 → 功能导航 → 5 列大海报。本方案按当前确认顺序调整为主导航 → 分类，并保留其层级比例与白灰浅色视觉。

## 3. 顶部三行

### 3.1 第一行：品牌 / 接口名 / 时间

- 高度：约 64dp
- 左侧 `ONEFILM`：28sp，SemiBold，字距略宽
- 中间当前接口名：20sp，SemiBold；有公告时优先显示公告
- 右侧日期时间：日期 `yyyy-MM-dd`，时间 `HH:mm`，等宽数字
- 全部距屏幕左右安全边距 48dp

### 3.2 第二行：主导航

固定顺序：

```
首页  搜索  收藏  历史  直播  配置  线路  网盘  设置
```

- 九项按内容宽度均分整行，图标 + 文字
- iOS 扁平化：无边框、无阴影、无外框，只有文字与轻量图标
- 焦点所在项显示深色胶囊高亮，白色文字；未聚焦项透明背景
- 高亮只跟随焦点，不固定在当前路由项
- 高度由文字和内边距决定，约 34dp，避免占用过多首屏空间

### 3.3 第三行：接口分类

- 来自配置接口返回的分类，第一位固定为 `主页`
- 从左往右自然排列，不做左右两端对齐
- 超出屏宽后整行横向滑动
- iOS 扁平化胶囊：无边框、无阴影；仅聚焦项显示深色胶囊
- 高亮跟随焦点，不固定在 `主页`
- 字号 14sp，高度约 30dp

### 3.4 导航绑定

| 导航 | 实际行为 |
|---|---|
| 首页 | Compose 首页 |
| 搜索 | Compose 搜索页 |
| 收藏 | Compose 片库，默认收藏 Tab |
| 历史 | Compose 片库，默认历史 Tab |
| 直播 | 旧版 `LiveActivity` |
| 配置 | 独立接口配置页：二维码 + 线路名称 + 点播/直播 URL |
| 线路 | 接口线路列表，选择后加载对应配置 |
| 网盘 | 本地目录 / WebDAV / Alist 网盘页，支持配置与浏览 |
| 设置 | Compose 设置页 |

### 3.5 页面头部显示规则

- 首页：品牌行 + 功能导航 + 接口分类全部显示
- 接口分类页：只显示接口分类行和电影卡片，不再显示品牌行、功能导航
- 收藏/历史：只显示片库自身的标题与 Tab，不显示全局头部
- 搜索：独立搜索页面，不显示全局头部
- 配置/线路/设置/详情/播放：不显示全局头部

网盘实现参考 `docs/ouge-netdisk-analysis.md`。

## 4. 首页内容

### 4.1 取消 Hero

TV 首页第一条内容直接是内容架，不再有大图 Hero。

### 4.2 5 列海报页

- 每页最多 10 张：2 行 × 5 列
- 卡片比例 2:3
- 卡片宽度按屏宽计算：`(屏宽 - 左右 48dp - 4 个间距) / 5`，5 列铺满整行
- 不为了强行塞下两行而缩小卡片；一屏放不下时纵向滚动
- 标题和评分叠加在海报底部，标题居中显示
- 左右键整页切换；上下键在当前页内纵向滚动
- 底部显示分页圆点（多页时）
- 首屏保持与欧歌影视相近的卡片体量，第二行露出一部分，提示可继续向下

### 4.3 统一电影卡片规范

首页、分类、搜索、片库必须使用同一套 TV 海报卡片：

- 5 列铺满屏宽，左右边距 48dp
- 列间距 16dp，行间距 24dp
- 海报比例 2:3，不使用小尺寸固定宽度卡片
- 标题与评分叠加在海报底部，标题居中
- 焦点：1.05 缩放 + 2dp 白色细环 + 轻阴影
- 无海报时显示统一的“无海报”占位
- 手机端继续使用原 `PosterCard`，不受影响

### 4.4 内容架顺序

1. 继续观看
2. 收藏
3. 推荐
4. 各接口分类内容

接口没有真实详情 ID 时，点击卡片继续走现有“聚合搜索”逻辑，不在 TV 层重写业务。

## 5. 搜索页

- TV 搜索页采用横向三栏：
  - 左栏：搜索历史、清空；历史词按宽度流式换行
  - 中栏：搜索框、搜索/远程搜索/清空/删除、A-Z + 0-9 满高字母键盘；字母只追加到搜索框，不自动跳结果
  - 右栏：关键字为空时显示电视榜/电影榜/综艺榜；输入关键字后改为动态匹配结果，点击匹配词才进入搜索结果页
- 搜索过程中保持现有并行流式聚合逻辑不变。
- 搜索结果页不再显示搜索框和搜索/重试按钮：
  - 左侧为站点列表和搜索进度，可切换「全部显示」或单个站点；站点名 23sp 居中
  - 右侧为 5 列 TV 海报卡片，卡片左上角显示来源站点
- 搜索历史、匹配结果、榜单词均按名字实际宽度从左到右流式排列，不固定列数。

## 6. 分类页

- 顶部保留三行结构
- TV 端不显示独立「筛选」按钮
- 再次点击当前接口分类标签时，从屏幕底部弹出筛选层，覆盖在卡片上方
- 筛选层不显示标题；每个筛选组占一行：组名在左，条件在右，整行可左右滑动
- 所有筛选组一次性显示，不做上下滚动
- 筛选层背景 50% 透明
- 选择筛选条件后筛选层保持显示，结果更新
- 返回键或点击筛选层外区域关闭筛选层，已选条件与结果保留
- 进入详情再返回分类页，仍保留原筛选条件与结果
- 内容同样使用 5 列铺满屏宽

## 6. 焦点与遥控器

- 所有可点击卡片/导航/按钮统一焦点样式：
  - 导航/分类使用 iOS 扁平胶囊：聚焦项深色底 + 白色文字，不缩放或仅 1.03 缩放
  - 海报卡片：`scale 1.05` + 2dp 白色细环 + 轻阴影
- 方向键：左右切换卡片，上下切换行/导航
- 确定键：进入详情/播放
- 返回键：先退出面板，再返回上一页
- 从详情返回首页：恢复原卡片焦点与页位置
- TV 页面控制条不自动隐藏（播放器另有规则）
- 高亮必须跟随焦点，不能固定在当前路由项

## 7. 组件拆分

```
compose/design/tv/
  TvHeader.kt          三行头部
  TvNavBar.kt          主导航
  TvCategoryRail.kt    接口分类
  TvPosterCard.kt      2:3 海报卡片 + 焦点
  TvPosterPager.kt     2×5 分页内容架
  TvFocus.kt           焦点缩放/描边/阴影
```

首页、分类页共用 `TvPosterPager`。

## 8. 实施步骤

1. 新增 `TvHeader`、`TvNavBar`、`TvCategoryRail`，只在 TV 分支渲染
2. 首页 TV 分支移除 Hero，接 `TvPosterPager`
3. 分类页 TV 分支改为分页横向
4. 焦点样式统一到 TV 组件
5. 手机分支保持现有 `HomeScreen` / `AdaptiveNavigation` 不变
6. TV 模拟器/手机 leanback 包验证布局与 D-pad
7. 真机电视验证

## 9. 验收

- TV 首屏能看到品牌、公告位、日期时间、9 个导航、接口分类
- 首页无 Hero
- 每页 2×5 卡片，横向整页滑动
- 分类页与首页卡片布局一致
- 遥控器焦点清晰，返回后焦点恢复
- 手机端界面零改动
