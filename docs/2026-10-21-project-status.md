# OneFilm 项目总进度与收尾清单

- 文档版本：2026-10-21
- 适用范围：`F:\APK\Onefilm`
- 文档地位：**当前项目进度的主文档**。旧文档与本文冲突时，以本文和 `compose-ui-roadmap.md` 为准；旧文档中保留的历史设计和交接内容不再作为实施依据。

## 1. 结论

UI 重构主体已经完成，项目进入收尾阶段。

| 阶段 | 进度 | 结论 |
|---|---|---|
| P0 基础/身份/构建 | 100% | 两 flavor 可构建，Compose 宿主机和旧 UI fallback 已建立 |
| M1 基础设施 | 100% | 设计系统、Bridge、导航、首页骨架完成 |
| M2 数据接入 | 95% | 首页、分类、搜索、详情、收藏、历史、网盘已接真实数据；旧来源兜底策略未完全收敛 |
| M3 Compose 播放器 | 90% | 旧 PlayerManager 内核已接入，控制条/轨道/解码/渲染/PiP/后台/预加载已接；TV 控制条形态和手机手势未完成 |
| M4 设置页 | 90% | 播放/解码/字幕/弹幕/预加载/接口/主题/二维码推送已接；网络代理、Hosts、超时未迁移 |
| M5 TV 回归 | 40% | x86 模拟器多轮验证通过；真机电视未完成完整 D-pad/返回焦点矩阵 |
| M6 收尾 | 10% | 旧 UI/bridge 未删除，UI 测试/截图基线/发布文档未完成 |

总体判断：**UI 重构主体约 85–90% 完成，收尾与真机回归约 40–50% 完成。**
当前最大风险不是功能缺失，而是 TV 焦点/返回行为在真机上的系统化回归，以及旧 UI 删除后的回归缺口。

## 6. 下一阶段建议顺序

1. **真机 TV 焦点矩阵**：首页 → 分类 → 搜索 → 详情 → 播放 → 设置 → 返回。

3. **收尾设置/播放器缺口**：网络代理/Hosts/超时、TV 控制条、手机手势、声道。
4. **引擎验证**：DLNA 真机、DV 样片、MPV 预加载、后台长稳。
5. **删除旧 UI/bridge**，补 Compose 测试/截图基线。
6. **发布合规**：LICENSE/NOTICE/源码 tag/版本说明。

## 8. 已知测试限制

- 客厅电视 `192.168.1.22:5555` 多次处于 offline。
- 手机 `e1096c9` 未连接。
- x86 模拟器缺少部分 ARM 原生库，详情播放/蜘蛛可能报 `EM_ARM` 或 Chaquopy 原生库错误。
- 模拟器触摸操作会进入 touch mode，程序化焦点请求不稳定；方向键测试更接近真实遥控器。
- 因此，本文件中的“已完成”以代码和构建/模拟器证据为准；真机焦点与播放稳定性必须单独回归。
